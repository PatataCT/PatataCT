# Titanes del Pleistoceno

Web educativa sobre los animales gigantes de la Edad de Hielo. **HTML/CSS/JS puro**, sin frameworks ni dependencias.

## Estructura

```
.
├── indexx.html          # Portada (Plantilla A)
├── mamuts.html         # Mamuts (Plantilla B)
├── depredadores.html   # Depredadores del Hielo (Plantilla B)
├── megafauna.html      # Megafauna Extinta (Plantilla B)
├── extincion.html      # jjj La Gran Extinción (Plantilla B)
├── plantilla.html      # Documentación de plantillas
├── styles.css          # Todos los estilos (paleta, animaciones, responsive)
└── script.js           # Scroll reveal, menú móvil, back-to-top
```

## Cómo verlo en local

Abre `index.html` con doble clic. No necesita servidor.

## Publicar en GitHub Pages

1. Sube todos los archivos a un repositorio nuevo.
2. En el repo → **Settings → Pages**.
3. Source: `Deploy from a branch` → Branch: `main` → Folder: `/ (root)` → Save.
4. La web estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Características

- 6 páginas separadas (no one-page).
- 2 plantillas distintas (`indexx.html` y la usada por los 4 capítulos).
- Enlaces principales con prefijo `jjj`.
- Enlace `plantilla` al pie de cada página → `plantilla.html`.
- Diseño cinematográfico oscuro (paleta hielo + naranja).
- Tipografías Cinzel, Spectral y Manrope (Google Fonts).
- Responsive (móvil/tablet/escritorio) con menú hamburguesa.
- Parallax, scroll reveal, hover suave, timeline, Top 10, comparaciones de tamaño.
